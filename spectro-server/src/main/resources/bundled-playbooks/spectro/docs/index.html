spectro

Classify the request, then brainstorm, spec, plan, build with review and finish; a bounded change takes a short design, a spike ends in a recommendation.

Decisions

Classify

Check
human check: asks “Which path does this request take: spike, bounded or architectural?”
Outcomes
spike to Probe
bounded to Short design
architectural to Brainstorm

Spec complete

Check
sections check: reads spec
Outcomes
pass to Spec nod
fail to Brainstorm
exhausted to cancelled
Ceiling
up to 3 rounds, then the outcome exhausted

Spec nod

Check
human check: asks “Does the spec say what you want built?”
Outcomes
yes to Write plan
no to Brainstorm

Plan complete

Check
sections check: reads plan
Outcomes
pass to Plan nod
fail to Write plan
exhausted to cancelled
Ceiling
up to 3 rounds, then the outcome exhausted

Plan nod

Check
human check: asks “Does the plan build the spec the way you want?”
Outcomes
yes to Set up worktree
no to Write plan

Review task

Check
review check: model standard (anthropic claude-sonnet-5-5), reads plan, task_report
Outcomes
pass to Tasks left
fail to Fix findings
exhausted to cancelled
Ceiling
up to 5 rounds, then the outcome exhausted

Tasks left

Check
open_items check: reads plan
Outcomes
pass to Final review
fail to Implement task

Final review

Check
review check: model judge (anthropic claude-fable-5-1), reads spec, plan
Outcomes
pass to Finish branch
fail to Fix final findings
exhausted to cancelled
Ceiling
up to 2 rounds, then the outcome exhausted
