# spectroscope 0.15.0, the Local mode and Copilot part

Paragraphs for the 0.15.0 release notes, written by the session that built
these cards. Fold them into release-notes/v0.15.0.md and keep the facts and
the numbers.

## Local mode

**A switch per chat for a local model.** The gear under the message box gets
a row "Local mode". Switched on, the chat gets its own settings: how many
model sessions it runs at once (the main agent plus its helpers, three by
default), a care paragraph in the system prompt that tells the model to work
in small steps on a shared GPU, a preset of tool groups, and a read share for
whole-file reads of 10 percent of the window, marked in the gear as a
proposal. Switched off, the chat behaves as in 0.14.4; the request to
Anthropic and OpenAI is byte-identical.

**Helpers wait for a slot.** A chat whose session count is three runs the main
agent and two helpers; a third helper waits for a free slot of that chat, and
the wait is visible in the chat and the Lab. The count reaches the tool
description, the schema and the runtime check from one source. The key
`sessionsPerChat` can also be set in a settings file, floor 2.

**Two limits follow the window.** The completion budget sent to a model is
at most what its context window leaves after the estimated input, with a
floor of 512 tokens: on an 8,192 window a request asks for 2,458 tokens
instead of 32,000, on a 200,000 window nothing changes. An image counts as
4,784 tokens of that input and a PDF page as 7,784, whatever their size in
bytes. An explicit compaction threshold at or above the window gets the
floor. The clamp on tool output follows the window as well: 6,144 characters
at 8,192 tokens, the usual 10,000 from 13,336 tokens up, and a blocking
hook's reason follows the same rule.

**Settings say when they take effect.** The reach vocabulary gains "next
run": the tool groups and the Local mode rows apply from the next run of an
open session, and the reference chapter names the reach of every key.

## Copilot

**GitHub Copilot as a provider, on macOS.** Pick copilot in the model menu,
sign in with GitHub in the app (the device flow shows a code and a link; you
approve in the browser), and the chat runs through the Copilot SDK against
your own subscription, with the harness keeping its own tool loop. The
runtime is the Copilot CLI installed with Homebrew; when it is missing, the
app says so and names the install line, and spectro doctor shows the state.
Usage is shown as the SDK reports it.

## Sessions

**A stored session shows its folder at once.** Selecting a chat in the list
shows its folder in the header chip before any message. A click into the
message box wakes the folder on the server, so Finder, Terminal and Build code
graph are available without sending anything and without a model call.
