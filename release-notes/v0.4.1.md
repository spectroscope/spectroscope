# spectroscope 0.4.1

Released 2026-07-27. `dev.spectroscope:spectro-core:0.4.1` and
`dev.spectroscope:spectro-orchestrator:0.4.1` are on Maven Central; the CLI,
the server, the MCP notes server and the macOS desktop kit are attached below.

## A third session format

VS Code and GitHub Copilot agent-mode exports can be loaded alongside
spectroscope's own JSONL and Claude Code transcripts. Tool outputs are not part
of that format, so the tool bodies in such a session are empty; the import says
so once.

A file in none of the three formats now names the record types it actually
contains, so you can tell what you picked up. Picking a file that cannot be
read reports the reason instead of doing nothing.

## Search

Press Cmd+F (Ctrl+F on Windows and Linux) to search the chat, the text feed or
the trace. Every occurrence is marked, Enter and Shift+Enter step through them,
and a checkbox reads the query as a regular expression.

The chat searches what it shows: your messages, the answers, the reasoning, and
the tool calls with their commands and results.

## Translation

A session can be translated into German or English, by the built-in local model
or by your configured cloud provider. The translation is applied to the session
itself, so the chat, the trace, the text feed, the graph, the spectrum and the
lab all show it at once. One click switches back to the original, and the
stored file is never changed.

Commands, file paths and tool output are left in place. The translated session
can be saved as JSONL and loaded again later.

## Export

Each tab exports what it shows: the chat and the text feed as a single HTML
file that opens without a network, and the event stream as JSONL. A translated
export is named and labelled as one.

## Imported sessions

- The model that produced each answer is shown, including when a session
  switched models part-way through.
- Prompt caching is shown per answer: how much was read from the cache and how
  much was written to it.
- A session's duration is its real duration. Durations over an hour are
  written in hours.
- One turn per exchange, so the graph shows the shape of the session instead of
  a single row.
- An imported session opens at its beginning, and the chat has a control to
  jump to either end.

## Reading a session

- Shell commands, SQL, Java, Python and JSON are syntax-coloured, in answers
  and on tool cards.
- Tool calls from Claude Code, VS Code and MCP servers are rendered as what
  they are: a command as a command, an edit as a diff, an image as the image.
- The trace's event detail has a structured view beside the raw event, and the
  lab offers the same choice.
- Host and model columns in the trace can be switched off, and a column this
  session has no data for is hidden.
- The timeline lens now starts off.

## Fixed

- Browser-side errors and warnings appear in the log pane next to the server's.
- The context gauge measures against the model's context window. It previously
  divided by a fixed number and could report over 100%.
- Scrolling over the read-only bar of an archived session no longer moves the
  whole page.
- A translation that is cut short says so, instead of reporting success with
  passages left untranslated.
- Settings section headings are readable and sit with the fields they name.

## Requirements

Java 21 or newer. The desktop kit is macOS arm64, signed and notarized, and
includes its own Java runtime. The server jar and the CLI need a `llama-server`
on the PATH (`brew install llama.cpp`) to run a local model; the desktop kit
brings its own.
