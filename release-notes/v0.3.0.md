# spectroscope 0.3.0 — DRAFT (unreleased)

**Not released yet.** This file collects what main has grown since 0.2.0, so
the release day is an edit, not an archaeology dig. Numbers and dates get
finalized at release time; the gate at draft time (2026-07-23) was
**JUnit 733 · vitest 501**, all green.

## The fleet machine room

Entering a fleet and opening the lab tab shows the whole fleet as ONE
agent-system diagram: every node its own agent loop on a shared machine — the
OS band lights for whoever is on it, remote providers sit beyond the network
boundary, a node on Ollama rails to a local LLM station inside, and a purely
local fleet shows no remote box at all. Its own replay transport scrubs,
plays (owner-tuned pace, tempo under MORE) and follows the live edge.

## Watching got sharper

- **The canvas talks now:** hovering a node's spectral band scrubs tick by
  tick with the Spectrum's preview popup — type, relative time, payload —
  and a click opens exactly that event in the trace.
- **compact | expanded**, in the Lab and the machine room: expanded opens
  every card — the context window and system prompt sit BESIDE the agent,
  the prompt beside the user, task & history inline on every node card. The
  layouts spread with the view, so nothing overlaps.
- **The real generated image** renders on the agent card (and the gallery
  panel): while `generate_image` runs you see the placeholder and the
  requested prompt; once done, the actual blob. Scripted scenarios can bundle
  a demo asset — the image-generation demo now ends on a real beach cat.
- **Timing bars by default:** the trace's timeline lens is on out of the box
  (log-scaled so one slow call cannot flatten the rest); the toolbar chip
  still switches it off, persistently.
- Fleets are **deletable** from the sidebar once every node is offline; a
  recorded scenario fleet no longer offers to spawn nodes into a replay; and
  loading a chat scenario cleanly LEAVES an entered fleet (header and tabs
  can no longer disagree).

## Explain, honestly

The text tab gained an LLM-backed **explain**: a bounded digest of exactly
what the tab renders goes to the configured provider and the reading streams
back — labeled as a model-generated interpretation of the recorded run, never
"model internals". The deterministic gates panel in the trace is untouched.
The endpoint wears the same local-origin + CSRF fences as the key writer,
because it spends the operator's key.

## Observability: OTLP built in

Every run can stream its spans to any OTLP/HTTP backend — Langfuse first
among them (its documented JVM path IS this endpoint). One setting pair
(Settings → Observability: endpoint + optional `pk:sk` Basic auth; env
`SPECTRO_OTLP_ENDPOINT` / `SPECTRO_OTLP_BASIC_AUTH`), a doctor line that
probes the endpoint for real (an empty, valid OTLP batch — green means spans
will land), and the export itself stays additive: the session JSONL is the
anchor, a dead backend warns once and never slows a run. Spans carry both
`langfuse.observation.type` and `gen_ai.*` semconv — agents, generations
with token usage, tools with input/output, gates (WARNING when denied).

## One render engine

The Lab, the fleet machine room, the simulator and the edu lessons now share
ONE canonical render engine (`spectro-web/src/lab/`, contract in `ENGINE.md`):
the per-agent scene fold, the node cards, the rails, drag-pinning (dragged
cards finally stay put), and the expand/declutter flags the shells opt into.

## Scenarios & starters

- Two new subagent choreographies: **Bug hunt · 3 lenses as subagents**
  (parallel fan-out over one diff, merged by severity) and **Research ·
  draft, attack, synthesize** (an adversarial reviewer attacks the draft;
  only what survives reaches the answer).
- The sidebar lists chat scenarios under *sessions* and fleet scenarios
  under *fleets* — no more mixed pile.
- Starter bundles render for **four tools** now: Gradle, Maven, **Python**
  (the real pre-release edition API — `spawn_agents` fan-out, no fleet-panel
  claims) and **bash** (the actual CLI: `spectro run`, `spectro node`
  choreographies against a hub). Escape closes all picker dialogs.

## Fixes worth naming

- `./spectro desktop` no longer pins a version-numbered server jar (it
  globs the newest — a bump can never break it again) and
  `./spectro web --port N` actually forwards the port. Both surfaced on a
  fresh clone of the 0.2.0 release; the playbook grew a fresh-clone smoke
  step because of them.
- A fresh browser now sees a fleet's recent history (parked gates included)
  — hydration pulls each node's ring replay instead of only the roster.
