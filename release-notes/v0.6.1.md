# spectroscope 0.6.1

Released 2026-08-04, hours after 0.6.0. A patch release, and the reason for it
is one line of the desktop shell: every start was a new address, and an address
is where a browser keeps your settings.

## The desktop app stops forgetting you

The shell asked the operating system for a free port on every launch. That is
sound for avoiding collisions and wrong for everything else, because the web app
stores its preferences against the origin it is served from. So `localhost:53441`
and `localhost:61092` are two different browsers as far as the saved state is
concerned, and every launch met an empty one.

The built-in model notice was the loud symptom: dismissed, and back the next
morning, and the morning after that. It was never the notice. Design, language,
disclosure level, the lab view and the timeline lens all reset on every start,
silently, and only the notice was rude enough to say so.

The port is now remembered next to the version marker in the app's own data
directory and tried first on the next launch. A port that is taken falls back to
a fresh one, which costs the preferences once and then settles again.

Nobody browsing to `:8080` ever saw this, and every live check this project ever
ran was a browser at a fixed port. That is why it survived so long.

## doctor stops calling a healthy install broken

On a clean clone `spectro doctor` ran every check green and then failed on the
provider check with `unknown provider spectro-local`, exit 1. That is the first
command the documentation suggests, ending in red on a machine with nothing
wrong. doctor knew three providers out of seven.

It now knows all of them, and the switch is drift-tested against the provider
list, so the next one cannot be forgotten the same way. Four more honesty
repairs travelled with it:

- A keyless `openai` was green because `api.openai.com` answers the probe, with
  a 401. Reachability and authentication are two lines now, and the second one
  fails loudly.
- A configured model the built-in catalogue does not carry was swapped silently.
  doctor names the model that will really run.
- The vision line branched on the name `ollama` and told everyone else their
  model "handles images natively". Nothing measures vision in this codebase, so
  four providers now say that plainly instead. The built-in one could be
  measured, and the answer is no: `llama-server` starts with the weights alone,
  no projector, so an attached image never reaches the model.
- A provider with no key variable, pointed at a public endpoint, was told the
  endpoint sat on its own machine. The verdict was right and the sentence was
  false.

## One filter fences the whole API

Sixteen handlers checked that a request came from loopback carrying a localhost
Host, the pair that defeats DNS rebinding, and twelve did not, including
`DELETE /api/sessions/{id}`. Nothing said which list a new endpoint belonged on.

The check is one filter now, default-deny, and the single deliberate exception
(`/api/health`) is a named line a drift test reads, so the published fence table
in `docs/api-collections/` cannot quietly disagree with the code. Being upstream
of argument binding also gives the explain endpoint a body cap that acts before
the body becomes an object.

The first cut of that filter matched the raw request target, and one escaped
character walked past it: `/%61pi/config` carries no literal `/api/`, so the
filter waved it through while the container decoded it and handed it to the
handler. Measured before the fix: the whole configuration, the whole assembled
system context, and a DELETE that took a session off disk. The filter now reads
the path the dispatcher reads.

## An imported response is one response

Claude Code writes one assistant record per content block, each repeating the
same message id and the whole usage object. The importer read every record as a
turn and every copy of the usage as a bill. Measured across 4,977 transcripts:
265,009 assistant records are 143,025 responses, and only 60,098 responses were
ever a single record. One session showed 1,321,954 output tokens where its file
records 599,435.

A response is one turn now, its tokens counted once, and the run survives its
tool results arriving between its pieces.

Two readings improved with it. The reasoning lens keyed the row that *closes* a
thinking block; on the measured transcript 146 of 146 two-row blocks carry their
longer row first, so the panel was drawn on the short tail. And the structured
face now prints the record's own fields under the frames they produced: model,
effort, request id, the skill or plugin or MCP server the turn is attributed to,
working directory, git branch, the cache split. An assistant record carries 25
fields; the importer read 9 of them.

## The ladder is called the tutorial

One rename, in both languages, across the app, the guide chapter, the generated
poster and the CLI. Stored values did not move: the mode on the wire is still
`ladder`, the level ids are untouched, and an existing `~/.spectro` reads
exactly as it did.
