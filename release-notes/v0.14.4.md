# spectroscope 0.14.4

This release lowers what a long chat costs to send and adds two commands,
a code graph and a complete import. Tool groups can be switched off per
session, old tool results leave the request before compaction, local backends
report what they already had in their cache, and the system prompt tells the
model to send a scout instead of reading a whole tree itself. `/compact` and
`/clear` work in the web chat. graphify runs from the app and its graph opens
in the internal browser. An imported session brings its wire along. The test
suite no longer pops desktop notifications, and those notifications have a
switch. The folder chip in the header keeps its name.

---

## Context

**Tool groups per session.** The gear under the message box lists seven tool
groups: browser, launch, images, web, agents, roles and mcp. A group that is
switched off is not sent to the model at all, so the "tool schemas" part of
the context ring shrinks with it. The choice is saved with the folder
(`toolGroupsOff` in the local settings), also before the first message, and
takes effect on the next run of that session. A child agent takes the groups of the run that spawned it. The
file tools, run_command, the plan, the question tool and the skill tools have
no group and are always sent.

**Old tool results leave the request.** A tool result that is older than four
turns and larger than 2,000 characters is replaced in the request by one line:
the tool, the path or the first word of the command, the size, and the note
that the tool can be called again. The session file keeps the full result, and
the trace and the Lab show it as before; the llm wire records what was sent.
The replacement happens in batches of at least 8,000 characters, so a cached
prefix on Anthropic survives between batches. The key `toolResultElision`
switches it off. Measured over 1,387 requests in 368 local sessions on
2026-10-09, the batches saved 25.7 percent of the conversation characters sent,
most of it in one session of 525 requests; without that session the saving is
4.9 percent, and the mean per session is 0.37 percent. In the two longest
sessions measured, 27 and 525 requests, the saving was 27.9 and 38.5 percent.

**Local backends and the prompt cache.** When `promptCaching` is on, requests
to llama.cpp and to the bundled local runtime carry `cache_prompt`; when it is
off, the field stays out and the server keeps its own default. The harness
reads the cached token count from the response and shows it in the context
ring, as it already does for Anthropic, and the session totals count only the
input the backend actually read. Measured on
2026-10-09 with a local llama-server and a 1.7B model over twelve turns: a
server started with its defaults caches on its own, so the field changes
nothing there; a server started with `--no-cache-prompt` re-read the whole
prompt on every turn (963 to 1,071 ms to the first token) and with the field
read only the new turn (35 to 38 ms).

**Discovery goes to a scout.** The system prompt now carries four sentences on
reading: a sweep across many files or folders goes to an explore child and the
parent works from its digest; a file the parent already needs is read
directly, with offset and limit when it is large; an edit that stands on its
own goes to a worker child; a child's task must be complete and must ask for a
digest, not for file contents. The paragraph adds 475 characters to the
prompt.

## Chat

**Two commands.** The slash picker lists `/compact` and `/clear` above the
skills. `/compact` folds the history now, between runs, and shows the
compaction the way an automatic one shows; while it runs the footer says
"compacting" and the stop button ends it. `/clear` keeps the session, its
file and its wire, and starts the next prompt with an empty history: a
divider marks the moment, and a reload or resume rebuilds the history only
from what came after it. Typing a partial command and pressing Enter
completes it; a second Enter runs it.

## Code graph

**graphify from the app.** The ⋮ menu and the folder chip offer "Build code
graph". A sheet asks for a full build or an update and for the backend and
model that name the communities, then graphify runs in the background on the
session's folder. The header shows the job while it runs; when it ends, a
"Graph ready" chip opens graphify-out/graph.html in the internal browser.
When graphify is not installed, the entry says how to install it, and
`spectro doctor` reports it. The graph page is served from the app's own port
for the chip press only; an agent cannot reach it through the browser tools
without allowLocalhost.

## Import

**An imported session finds its wire.** A session records the names of its
llm wire, its browser wire and its child sessions in its first event. Export
offers a bundle with all of them; import takes the bundle, or a plain session
file with its sidecars dropped beside it, and for a plain file whose wire
lies in this machine's `~/.spectro/llm-wire/` it asks the server for it by
name. Every LLM interaction of an imported session opens in the chat and in
the Lab. The import bar says what it found and what it did not.

## Desktop

**Notifications have a switch.** `desktopNotifications` in the user settings
turns the macOS notifications of cron jobs off; `spectro doctor` prints its
state. The test suite can no longer reach the desktop: every test that runs a
job records what it would have shown instead of showing it.

**The folder chip keeps its name.** The chip next to the session title no
longer shrinks with the title. A long title runs into its ellipsis first, and
the folder name stays readable, flush left after its icon, with icon and caret
at full size. A folder name longer than 24 characters is cut with an ellipsis
and shown in full when you point at the chip.

## Known limits

- In a stored session opened read-only, the "Graph ready" chip shows the
  recorded browser steps, not the graph.
- An answer that reported no usage line has no "LLM exchange" opener in the
  chat; the Lab's strip still opens it.
- A resume after `/compact` rebuilds the history from the file, so the
  compaction is not replayed.

- The guide exists in English only. The gear's strings are in English and
  German.
- The context ring popover does not yet show the cached share as its own
  number; the total reflects it.
- The System context panel of the guide was not re-captured for the new prompt
  paragraph; the text in the guide is current.
