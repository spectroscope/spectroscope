The picture is the product's own metaphor: the repo is the source, the build is the prism, and each server downstream is one spectral line. A line that answers is lit; one that does not is drawn faint and dashed, because a server you have not started is not a failure.
Liveness is a no-cors probe — it can tell a door from a wall, and nothing more. It never reads a response, so nothing here can leak out of a service.
Start the build stacks with ./ci/spectro-ci up jenkins · the app with ./spectro-serve start · the board with ./spectro-board start.
