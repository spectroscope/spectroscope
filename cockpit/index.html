Each running thing is one spectral line, drawn at the strength of its evidence: answering is lit, not answering is faint and dashed, and nothing is omitted.
The facts come from serve.py on this page's own origin — docker is asked, listening ports are read, spectro servers are found by their own health answer, and fleet state is read where a server answers.
Buttons run only scripts that already exist: ./spectro-env up|down <stack> and ./spectro-serve start|stop. This page: ./spectro-cockpit start.
