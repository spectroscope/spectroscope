# Insomnia: import the Postman v2.1 file

Insomnia imports Postman Collection v2.1 directly — use `spectroscope-api.postman_collection.json`
from this folder. We deliberately do not ship a hand-written Insomnia v5 YAML: the format is
young, has open importer bugs, and Insomnia's own docs route migrations
through the Postman format.

In Insomnia: **Application menu → Import** (or `Import` from the collection
list), pick the file, confirm. Postman v2.0/v2.1 is on Insomnia's official
importer list (developer.konghq.com/insomnia/import-export/).

## After the import: create the variables

The import carries the folders, requests and docs — but not the collection
variables: converting this file with Insomnia's own `insomnia-importers`
library yields all folders and requests and zero environment resources
(measured 2026-07-30; if your Insomnia build did import them, skip this
step). Open the collection's **Base Environment** (Manage Environments)
and paste:

```json
{
  "baseUrl": "http://localhost:8080",
  "sessionId": "20260730-120000-abcdef12",
  "nodeId": "node-1",
  "skillName": "brainstorming",
  "bundleId": "five-lines",
  "localModelId": "qwen3-4b",
  "imageFile": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef.png",
  "transcriptPath": "-Users-you-project/session.jsonl",
  "workspaceFilePath": "README.md",
  "scaffoldDir": "/tmp/spectro-scaffold"
}
```

`baseUrl` is deliberately pre-resolved — edit it in place if your server is
not on `localhost:8080`. The other entries are the placeholder ids the
parameterised requests reference (`sessionId`, `skillName`, …); each
request's docs say which list endpoint hands out real values.

One thing to know about the fences: several endpoints are origin-gated. A
desktop REST client sends no browser `Origin` header, which the server treats
as safe — from the same machine, every request in this collection passes.
Details and measured status codes are in the collection description and in
`README.md`.

This file is generated by `build_api_collections.py` — do not edit it by hand.
