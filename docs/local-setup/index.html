local setup

This page lists what spectroscope needs on your machine, level by level. Level 1 is all you need to run the app. The levels after it are optional, and one route per level is enough. Mark a step with "I have this" and the ring of its level fills.

0 of 22 steps marked

macOS means Apple silicon. Linux means Debian 12 and 13, Ubuntu 22.04 and 24.04. Windows is not covered. (README.md Apple silicon only, S37, S39, S53, S54)

before you start

Homebrew The macOS commands marked "needs Homebrew" use it, and so does the speech script. If brew is not found, install Homebrew first. Its page shows the install line and explains what it does. The DMG needs no Homebrew. brew.sh (S1, README.md is the same kit without the tap, setup-stt.sh Homebrew missing)

git The commands marked "needs git" clone a repository. To install git, run brew install git, or xcode-select --install for Apple's git in the Command Line Tools. git-scm.com (S48)

git The commands marked "needs git" clone a repository. To install git, run sudo apt-get install git. git-scm.com (S49)

Docker's apt repository The Linux Docker command installs packages from Docker's own apt repository. Add that repository first, with the lines on Docker's install page for your system. Docker on Ubuntu and Docker on Debian (S37, S38, S39)

cmake and a C and C++ compiler The whisper.cpp build lines on Linux call cmake and a C and C++ compiler. Install both from your distribution first. The whisper.cpp README shows the build. whisper.cpp README (S24)

Ollama The Linux line marked "needs Ollama" talks to a running Ollama. Install Ollama first, with its installer or the manual route on its Linux page. Step 2.2 quotes the installer. docs.ollama.com (S12)
